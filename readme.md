# Master Export - Laravel Package

![PHP Version](https://img.shields.io/badge/PHP-^8.1-blue)
![Laravel Version](https://img.shields.io/badge/Laravel-^10.0|^11.0-red)
![License](https://img.shields.io/badge/license-MIT-green)

یک پکیج قدرتمند برای خروجی گرفتن از داده‌ها در فرمت‌های مختلف در لاراول

## 📋 قابلیت‌ها

- ✅ خروجی Excel (xlsx, xls)
- ✅ خروجی PDF
- ✅ خروجی Word (docx)
- ✅ خروجی Image (PNG)
- ✅ خروجی Text (TXT)
- ✅ پشتیبانی از دیتای تو در تو (Nested Data)
- ✅ قابلیت شخصی‌سازی فیلدها
- ✅ پشتیبانی از زبان فارسی

## 📦 نصب

```bash
composer require mastertek/master-export
```
